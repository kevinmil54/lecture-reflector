# Lecture Reflector
**A product of [Kevin Miller](https://timelysnow.com) and Timely Snow LLC**


*Lecture Reflector* records a lecturer (webcam + mic) composited live with their slides — PowerPoint, Keynote, or reveal.js/Quarto in a browser — into a single MP4 with slide-change chapters, then generates a transcript (`lecture.txt` + `lecture.srt`) on-device with Whisper (WhisperKit). Six live-switchable layouts including a person-segmented "Floating Torso" mode; the slides and the lecturer can each be moved and resized by dragging in the preview; browser toolbars can be cropped off; crash-safe fragmented recording; pause/resume.

Docs: [LectureReflector_spec.md](LectureReflector_spec.md) (design), [LectureReflector_Mac_development_report.md](LectureReflector_Mac_development_report.md) (report), [LectureReflector_users_guide.md](LectureReflector_users_guide.md) (user's guide). Original browser prototype and report from Gemini: `gemini-code-1783873201727.html`, `kanfa_development_report.md`.

## Build & run

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) — regenerate after adding/removing files; don't hand-edit `LectureReflector.xcodeproj`.

```sh
xcodegen generate
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project LectureReflector.xcodeproj -scheme LectureReflector -configuration Debug \
  -derivedDataPath "$HOME/Library/Caches/LectureReflectorBuild" build
open "$HOME/Library/Caches/LectureReflectorBuild/Build/Products/Debug/LectureReflector.app"
```

(The `DEVELOPER_DIR` override is needed because `xcode-select` on this Mac points at CommandLineTools. Derived data must live **outside** this folder: the project sits on the iCloud-synced Desktop, and File Provider stamps extended attributes on build products there, which makes codesign fail with "resource fork, Finder information, or similar detritus not allowed".)

## Using it

See [LectureReflector_users_guide.md](LectureReflector_users_guide.md) for the full guide. Short version:

1. Open your slides (PowerPoint, Keynote windowed play, or the deck in a browser).
2. In Lecture Reflector: pick the slides window (or *Entire screen*), camera, and microphone → **Start Preview**. For a deck in a normal browser window, raise *Crop slides ▸ Top* until the toolbar is gone.
3. Pick a layout (Rectangle/Circle PiP, Sidebar, Floating Torso, Slides/Camera Only — switchable live; choose Sidebar *before* recording for the wide 1600×720 frame). Drag the orange box (slides) or blue box (you) in the preview to move them; drag a corner to resize.
4. **Record** (3-2-1 countdown) → lecture (Pause/Resume available) → **Stop Recording**.
5. The MP4 is finalized in seconds; transcription runs after and saves `lecture.txt` / `lecture.srt` / `chapters.txt` next to `lecture.mp4` in `Lecture Reflector <title> <date>` inside your chosen output folder (default: Movies).
6. To cut the video by its transcript, delete lines or words in `lecture-edit.txt` and click **Cut Video from Edited Transcript…**. This writes `lecture-edited.mp4` plus matching `.srt`/`.txt`; the original is untouched. Word timing comes from WhisperKit (`lecture-words.json`); the cut logic is in `Sources/Edit/`. From the command line: `LectureReflector --cut "<recording folder>"`.

## Permissions

- **Screen Recording** — prompted on first launch (needed to list/capture windows). After granting, quit and relaunch.
- **Camera** and **Microphone** — prompted on first Start Preview.
- The app is signed with the "Apple Development: Kevin Miller" certificate (team `YCTW9YH58J` in `project.yml`), so permission grants persist across rebuilds. If macOS ever silently denies screen capture without prompting (stale TCC entry), run `tccutil reset ScreenCapture com.kevinmiller.lecture_reflector` and relaunch.

## Notes

- First transcription downloads the selected Whisper model (~150 MB for `base`) from Hugging Face; afterwards it works offline. Model selectable in Settings (base/small/medium/large-v3).
- Recording is crash-safe: it writes a fragmented `.mov` (5 s fragments) and remuxes to MP4 on stop. After a crash, the partial `lecture.mov` in the session folder is still playable.
- The slide window must not be minimized (occluded is fine). When a deck goes full screen in a new window (Safari, reveal.js "F", Keynote), capture follows it automatically; the *Capturing* line shows the window being recorded. *Entire screen* is the fallback for full-screen presenting.
- Window capture is scaled to fill the frame (`scalesToFit`), so windows on non-Retina displays no longer appear small in the top-left corner.

## Installing into /Applications

```sh
./install.sh
```

Builds Release, quits any running copy, replaces `/Applications/LectureReflector.app`, and checks the installed version. With `./autobuild.sh` running, creating a file named `.install-request` in this folder does the same; results go to `build-output/install.log`.
